# Micro Frontend HTML Composition

This example demonstrates the core concept of Micro Frontends by composing a single web page from multiple independent UI components. Each component, like a header, product list, or shopping cart, is simulated as a separate "micro-frontend" loaded into a designated area of the main application. It illustrates how different parts of an application can be developed and managed independently, then integrated into a cohesive user experience.

## Language

`html`

## How to Run

Save the code as `index.html` and open it in any web browser.
